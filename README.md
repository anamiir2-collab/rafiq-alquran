## ✨ المميزات الرئيسية

- 📅 **خطة حفظ يومية ذكية** — يبني للمستخدم خطة مخصصة بناءً على هدفه الزمني وسرعة حفظه.
- 📝 **أوضاع متعددة للحلقة**:
  - **حفظ** (Memorize): عرض الآيات مع تكرار وتسميع.
  - **مراجعة** (Review): إعادة ما تم حفظه.
  - **تقييم** (Evaluate): تقييم ذاتي بدرجة من 1–10.
- 🧪 **وضع الاختبار** (Test): اختيار السورة ثم اختبار تسميعي مع نتيجة فورية.
- ❌ **سجل الأخطاء** (Mistakes): تتبّع الآيات التي يكثر الخطأ فيها لإعادة مراجعتها.
- 📆 **تقويم الحلقات** (Calendar): عرض تقدم الخطة على تقويم شهري.
- 📊 **التقارير** (Reports): تقارير أسبوعية/شهرية ونهائية مع إحصائيات الأداء.
- 🏆 **الإنجازات** (Achievements): شارات ومكافآت تحفيزية.
- 🌙 **الوضع الليلي** (Dark Mode) + 🌐 **دعم RTL كامل**.
- 💾 **حفظ محلي** عبر `localStorage` — لا تفقد بياناتك عند إغلاق المتصفح.

## 🚀 طريقة التشغيل

### الطريقة 1️⃣ — فتح مباشر
1. حمّل المشروع أو استنسخه (Clone).
2. افتح ملف `index.html` في أي متصفح حديث (Chrome / Firefox / Edge / Safari).
3. التطبيق جاهز للاستخدام فوراً ✅

### الطريقة 2️⃣ — تشغيل عبر خادم محلي (موصى به)
```bash
# باستخدام Python 3
python3 -m http.server 8000

# أو باستخدام Node.js
npx serve .

# ثم افتح في المتصفح:
# http://localhost:8000
```

> **ملاحظة:** التطبيق يعمل بدون خادم، لكن استخدام خادم محلي يضمن عمل الخطوط والصور بشكل صحيح في كل المتصفحات.

## 📦 بنية الكود البرمجي

### `js/app-data.js` (1450 سطر)
يحتوي على:
- `SURAH_META` — بيانات السور الـ 114 (الاسم، عدد الآيات، نوع الوحي).
- `EVALUATION` — منطق تقييم الحلقات.
- `UTILS` — دوال مساعدة عامة.
- `PLAN_ENGINE` — محرك بناء الخطط الذكية.
- `STATE` — إدارة الحالة العامة للتطبيق.
- `TOAST` — نظام الإشعارات المنبثقة.
- `ICONS` — مكتبة أيقونات SVG مدمجة.

### `js/app-ui.js` (1100 سطر)
يحتوي على:
- `Router` — تنقل بين الشاشات (Dashboard / Day / Test / Reports...).
- دوال العرض `render*` — كل شاشة لها دالة عرض مستقلة.
- معالجات الأحداث والتفاعل.
- شاشة الإعداد الأولى (Onboarding).
- إعدادات المستخدم والخطة وإدارة البيانات.

## 🎯 كيفية الاستخدام

1. **عند أول تشغيل** سيطلب منك التطبيق إدخال:
   - اسمك.
   - عدد الصفحات التي تريد حفظها يومياً.
   - تاريخ بدء الخطة.
   - السور التي تريد البدء بها.

2. **في الصفحة الرئيسية** ستجد:
   - حلقة اليوم (حفظ + مراجعة + تقييم).
   - نسبة التقدم في الخطة.
   - روابط سريعة للاختبار والأخطاء والتقارير.

3. **بعد إتمام كل حلقة** سيتم تحديث تقدمك تلقائياً وحفظه محلياً.
